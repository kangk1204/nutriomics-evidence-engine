# Food compound extension source audit

This extension uses the September 2022 FooDB snapshot supplied by the original study authors in [SWi1/FooDB_polyphenol_analysis](https://github.com/SWi1/FooDB_polyphenol_analysis), pinned to commit `3d2bcf9523911fabc8a07c731226ac87a2af262e`. It is a historical dataset, not a claim that current FooDB was downloaded in 2026. Every source file must match its pinned Git blob and SHA256; both compressed CSVs are read through bzip2 EOF.

[Wilson et al., J Nutr 2024](https://jn.nutrition.org/article/S0022-3166%2824%2900461-9/fulltext) explicitly links the author repository in its Data Availability statement and dates the FooDB download to September 2022. [USDA ARS publication 410641](https://www.ars.usda.gov/research/publications/publication/?seqNo115=410641) independently confirms the authorship, publication and DOI. The repository provides previously public food-composition files; the participant diet data still require a separate request and are not acquired here.

The [FooDB FAIR license statement](https://foodb.ca/compliance) assigns data and metadata CC-BY-NC-4.0. [FooDB About](https://foodb.ca/about) requires permission for commercial use. The repository MIT license applies to code; it does not relicense third-party data. Research analysis with attribution is permitted by the noncommercial data license. This project's policy excludes raw and derived data from Git. That policy does not mean the upstream license prohibits every noncommercial redistribution. Direct FooDB requests returned403 during this audit; the author-published files were accessible without credentials or access bypass.

The provided data dictionary documents shifted structure column names. In this specific snapshot, `cas_number` contains SMILES, `moldb_inchikey` contains InChI, and `moldb_smiles` contains full InChIKey. We bind by that documented schema and independently regenerate the full key from both SMILES and InChI. Connected single structures, stereochemistry and unresolved stereoelements are retained. Names alone never validate chemical identity.

Content rows in the `Nutrient` namespace do not become compound IDs. HMDB/PathBank predicted presence, broad plant/taxonomy links, unknown/manual records without specific references, zero-only observations and physically impossible mass values are excluded. DUKE records require the exact paired foodID and edible part from the published authors' curation, avoiding a broad independent ID/part allowlist. The original script used independent membership checks; this implementation preserves paired membership. Food composition and specific published food records are retained as distinct evidence tiers. Original amounts, units, citations, preparations and source food parts remain queryable.

[Foroutan et al. 2019](https://pubmed.ncbi.nlm.nih.gov/30994344/) describes 296 measured milk metabolites or molecular species corresponding to 1,447 possible structures. Accordingly, exact standardized structure representations associated with food occurrence are distinct from individually resolved native chemical forms. Positive numeric rows can represent molecular-species assignments or ranges. The extension reports these limitations explicitly; it does not claim 1,447 separately resolved milk stereoisomers, new experiments, free-ligand exposure, or compound-specific dietary dosage.

Other bounded source checks did not establish additional downloadable verified food occurrence: LOTUS organism occurrence lacks edible-part evidence; FoodAtlas current bundles require an issued API key; and the existing NutriOmics_DB_c planning documents contain synthetic seed warnings and manifest-only count claims. None of those unverified counts are added here. The previous 33-standard DTI panel and its evaluated subsets remain unchanged.

The broader snapshot retains 4,630 standardized structures for exploration. A separate strict audit requires original analyte identifiers and exact source chemical names after native-ID and structure verification. Positive numerical records and amount-free identified presence with a specific publication are counted separately. Milk species assignments, generic classes, elemental totals, unresolved standard stereochemistry and ambiguous methods are excluded. The lack of an amount does not itself exclude a qualitative record, while a database or taxonomic assignment without a specific source does. Conservative exact-name comparison can reject real synonyms and therefore does not estimate total food chemistry.
