## 분모와 연결 범위

실제 접근 가능한 `docs/graph_allrow_20261003_v3.json`의 예시6건 전부를 확인했다. 이는 **식품1개·성분1개·조성 측정1건·유전자5개·성분–유전자 edge5개**이며, PTGS2의 marker/therapeutic 경로는 동일 성분–유전자 edge를 재사용한다. 이5개 유전자는 현재22개 native 위치 유전자와 겹치지 않는다(예시6건 중0건). 별도 전체 graph나4,630개 성분의 교집합으로 외삽하지 않는다.

별도 extension receipt의 표준 구조4,630개는 양수 수치 조성 연결2,563개+정성만2,067개다. 측정 조성337,004행+정성8,620행=345,624행이다. September2022 원자료의 역사적 snapshot이며, 수치 조성 행·표준 구조 일치가 임상 효과나 원 식품의 입체화학·실제 생체노출을 확정하지 않는다.

**전체4,630개와 실제 모델의 연결 건수/미검증 건수는 현재 계산 불가이므로 JSON에서 null로 유지했다.** serving DB와 extension의 실제 행을 읽지 못했으며, 이6건은 별도 선택 graph의 예시다. 4,630개 전체를 검증했다고 하지도, 전부 실패했다고 하지도 않는다. 별도 DB RC6의0 qualified/replicated chain과0 독립 benchmark 기록은 pinned README의 동결 상태이며 재실행 결과가 아니다.

## 유지한 한계와 음성 결과

- FISHGASTRO: GEO28명·학회31명 불일치 미해결; 개인별 임상 crosswalk 없음; nominal1,202유전자는 FDR 미통과; **발현 자료이고 DNAm이 아님**. GSE15284는 이번 접근에서 reCAPTCHA였으며 새 분모 조정이나 재분석을 하지 않았다.
- 영양 중재 조직, 극단 비만 수술 표본, 혈액/지방세포, 인간 세포주/환자, 쥐 세포, 공동처치와 단독노출을 분리했다.
- 모델의 계수·예측, 관측 연관, 실험의 제한된 직접 효과, 미검증 연결을 별도 evidence_class로 저장한다. 분류 계수를 유전자 발현 방향으로 변환하지 않는다.
- 독립 참가자 분할·재사용 코호트·개인 공변량·probe SNP/교차반응·결측4개 위치·조건부 구간의 한계는 기존 기록에서 유지한다. 새 누출 검사가 수행됐다고 주장하지 않는다.
- 1차 초록으로 확인한 PTGS2 방향은 증가이며, 억제제 대조와 공동처치 조건을 없애지 않는다. [Kim et al., PMID15210717](https://pubmed.ncbi.nlm.nih.gov/15210717/)
- Nrf2/보호의 여러 성분 요약은 EGCG별 효과량으로 쓰지 않았다. [Hanneken et al., PMID16799064](https://pubmed.ncbi.nlm.nih.gov/16799064/)

## 파일과 검증

- `evidence.json`: 실제50개 CpG,11개 근거 기록(연관4·제한된 직접 실험2·계산 예측1·미검증4),선택 경로6건,분모·제약·보강 전후·필요 증거.
- `evidence.schema.json`: DOI/PMID,종/조직,설계,n과단위,용량/기간,방향/효과량/CI/FDR와검정가족,정확 지지 범위,음성/실패,누락 근거. 알 수 없는 값은 null로 기록.
- `verify.mjs`: JSON/schema 및 분모·중복·방향·조건·미적용 상태의 구조 검증. 기존 모델·API 테스트를 대신하지 않는다.
- `validation.json`: V8에서25개 검사 통과(5개 오류 주입 검사를 포함). 로컬 Node/pytest·모델 재실행은 미수행이다. schema 검사는 사용한 keyword의 경량 검증이며 공인 전체 validator 실행이 아니다.

기록11건은11개 독립 연구가 아니다. P01와M01은 같은 보고 모델/참가자를 공유한다. 원문 논문 전체·데이터·저작물은 이 패키지에 복제하지 않았으며, ID·출처·간결한 근거 요약만 저장했다.

## 적용 전 보강 순서

1. 동일 Mac 연결 복구 후 현재94쪽 산출물과 원장 해시·파일 소유 작업·관련 로컬 지침을 확인한다.
2. 원본 serving DB/extension을 read-only로 대조하여 전체4,630개→실제22개 유전자/50CpG의 정확 연결·불일치·미검증 분모를 계산한다. exact structure identity와 source-reported bridge를 구분한다.
3. 이미 보유한 소규모 McAllan 보충표에서 ST7/ST9/ST11 행·유효n·효과량·통계·검정가족을 대조한다. 새 cohort/훈련/원자료 대량 다운로드로 확대하지 않는다.
4. API 담당자가 이 문서 패키지를 검토한다. 엄격 v2 qualification/AI-review import에 필요한 전체 가족 checksum·원자료·실험 맥락·검토 provenance가 없으므로 이 패키지를 qualification 입력으로 취급하지 않는다.
5. 검토가 완료된 근거만 보고서에 반영하고, 추가 실험·개인 임상자료가 필요한 연결은 미검증으로 남긴다.

이번 산출물은 연결 맥락과 확인 범위를 구체화했다. 식품→성분→현재 패널→건강 효과 전체 연쇄나 임상 개선은 새로 입증되지 않았다. 학습·최적화·코호트 확대·대형 다운로드·보안/자격 변경·예약·외부 제출을 재개하지 않았다.
