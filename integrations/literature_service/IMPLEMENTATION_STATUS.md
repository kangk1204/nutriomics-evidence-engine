전체 수집 및 동일 기간 대조에서 **597개 고유 PMID**를 확보했습니다. 주제별 중복을 포함한 검색 결과는 고혈압·후성유전 228, DASH 128, 오메가3 77, 비타민D 83, 카페인 66, 코코아·플라바놀 27편입니다. 모든 주제의 검색 수와 반환 수가 일치했습니다. 597편의 OA 확인을 마쳤으며 명시적 라이선스를 확인한 공개 XML 본문은 **325편(54.4%)**입니다.

HGNC 공식 자료는 45,140개 Approved 레코드로 동결했습니다. 자료 SHA-256은 `91d0ad20c34f26fb12c8cce3f80a65a6fc694f3a508040b19f6bfa29ae0d889e`입니다. 엔진은 `heuristic-v1`, 규칙은 실제 소스 바이트의 `rules-sha256:c20123d32695fb090df435ece134e7bbf121fc3a2b0500f5f6d7dd56ab3bbd70`입니다.

최신 규칙으로 **597편 전체의 요약**을 완료했습니다. OA·추출 큐는 각각 597건 완료이며 대기·실패 작업은 0건입니다. 현재 관계 후보는 **1,465건**, 사람의 승인 관계는 **0건**입니다. 운영 중 최신 수는 화면의 실행 상태 또는 `/api/v1/runs`에서 조회합니다.

## 검증 결과

Linux 운영 환경에서 최종 **132개 테스트와 Ruff 검사**를 통과했습니다. Windows 개발 환경에서도 동일 기능을 검사했습니다. 수집 누락·중복·기간 분할·429/시간 초과, 검색식/주제 변경, 검색에서 제외된 기존 논문의 철회 갱신, 정확한 원문 위치, 종·부정·선행연구, 인증·검수·재검토, 리포트 동결·백업 복원·KST 스케줄·평가 표본의 변경 차단을 검사합니다.

운영 API를 사용한 Streamlit AppTest에서 5개 화면, 논문 상세, 후보 그래프와 리포트 다운로드 준비가 통과했습니다. 이 검사는 시각 디자인의 픽셀 검사를 대신하지 않습니다. 실제 원본 파일/텍스트 해시와 모든 저장 후보의 문자 위치 검사에서 오류 0건을 확인했습니다. SQLite integrity/FK 검사와 실제 운영 백업의 별도 임시 DB 복원도 통과했습니다.

추출 worker PID `884600`을 SIGKILL로 종료했고 supervisor가 PID `884690`으로 재시작했습니다. 남은 큐를 회수해 실제 처리를 재개했습니다. 별도 `process --stage extract`는 실행 중인 worker의 잠금으로 거부됐습니다. 이 서비스의 전체 프로그램 중지/시작도 통과했습니다.

실제 개인 계정으로 로그인·로그아웃을 검사했습니다. 이 검사에서 문헌의 승인·수정·기각은 수행하지 않았습니다. 최종 배포의 supervisor PID는 API `887167`, UI `887168`, 추출 `887169`, OA `887170`이었습니다. PID는 이후 자동 재시작 시 바뀔 수 있습니다.
